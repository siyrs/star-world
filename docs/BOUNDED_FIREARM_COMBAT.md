# 有界枪械战斗合同

## 目标

本迭代增加三类游戏内热武器枪械：星火手枪、拓荒卡宾枪和裂岩霰弹枪。它们必须复用既有制作、背包、装备、输入、战斗、UI、存档和第一人称模型系统，而不是成为平行小游戏。

## 内容边界

`data/firearms.json` 是独立扩展文件：

- 火药、轻型弹药、霰弹；
- 星火手枪：半自动，8 发弹匣；
- 拓荒卡宾枪：全自动，24 发弹匣；
- 裂岩霰弹枪：泵动，5 发弹匣、7 条命中射线；
- 所有制作配方使用现有工作台与既有材料；
- 物品、配方和 profile 与基础数据、弓箭数据一起原子 staged，重复 ID 整体拒绝。

## 权威所有者

```text
RangedWeaponRegistry
  └─ 只读参数与硬限制

RangedCombatService
  ├─ 主动作状态
  ├─ 半自动 / 全自动 / 泵动节奏
  ├─ 有界换弹计时
  ├─ 弹匣事务
  └─ ProjectileRuntime + HitscanRuntime

EquipmentService
  └─ main_hand.metadata.magazine_rounds

CombatService
  └─ 唯一伤害、防御、击退、受击与击败结算
```

## 弹匣与换弹原子事务

弹匣属于具体武器实例，不属于玩家全局状态。它与耐久、自定义名称一起放在装备元数据中。

```text
请求换弹
→ 验证枪械、弹匣未满、存在备用弹
→ 进入 transient reload
→ 不提前扣备用弹
→ 完成时计算 min(缺口, 备用弹)
→ Inventory.transact_items 原子扣除
→ EquipmentService.update_slot_metadata 更新弹匣
→ 更新失败返还备用弹
```

取消、换武器、世界切换或关闭服务不会消耗备用弹。换弹进度不进入存档；已完成的弹匣数量通过既有 equipment schema 保存。

## 开火事务

```text
验证枪械 / 非换弹 / 冷却完成 / 弹匣有弹
→ 弹匣减 1
→ HitscanRuntimeService.resolve_shot
→ 查询失败则弹匣回滚
→ 成功后消耗 1 耐久
→ 进入数据驱动射击间隔
```

全自动只在主动作保持且冷却归零时发射；最短间隔为 0.06 秒。弹匣为空时自动停止继续发射。

## 有界命中扫描

- 每枪最多 12 条射线；
- 最大命中距离 128 格；
- 最大扩散角 12 度；
- 没有逐弹丸 Node、Timer、线程或世界扫描；
- 命中方向使用确定性的黄金角分布，测试可复现；
- 攻击者 RID 被排除；
- 同一目标的霰弹命中先聚合，再只调用一次 `CombatService`；
- `pellet_hits` 进入结果与 UI 事实，但不会造成重复击退或重复击败。

## 输入合同

- 鼠标左键与手柄右扳机共享 `primary_action`；
- 键盘 `R` 与手柄左肩键共享 `reload`；
- 玩家和枪械服务只读取逻辑动作；
- 生产枪械代码不得包含物理键码或 `JOY_*` 常量。

## 第一人称显示

第一人称视图模型采用主手装备优先，背包选中格回退。手枪、卡宾枪和霰弹枪分别生成不同的程序化像素模型，保持：

- 无碰撞；
- `no_depth_test` 近裁剪保护；
- 现有行走摆动、切换、使用和后坐力反馈；
- 弹匣元数据变化不重建模型。

## 持久化边界

保存：

- 备用弹药：现有 inventory；
- 武器与耐久：现有 equipment；
- 已完成装填的 `magazine_rounds`：装备 metadata。

不保存：

- 扳机保持；
- 射击冷却；
- 换弹进度；
- hitscan 统计；
- 后坐力与 HUD 瞬态。

因此无需修改 `world.json` schema，也不存在第二枪械存档服务。
