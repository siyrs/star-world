# 产品路线图 · Iteration 55

## 本轮完成范围

### 可玩性

- 数据驱动的敌对小队；
- 前卫、远程支援和重装终结者角色；
- 深渊游猎队、深渊突袭队和普通夜行巡猎队；
- 有界编队半径；
- 当前遭遇 HUD；
- 低血量自动降压；
- 枪械逐个击败与遭遇完成闭环。

### 架构

- 原子 Encounter Registry；
- 纯 Encounter Policy；
- 每秒一次的单 Director；
- 2 个活动遭遇、12 个成员、8.0 危险预算硬上限；
- WeakRef 局部成员追踪；
- 复用原 CreatureSpawner、CombatService、生态和存档；
- 场景显式组合，不替换稳定 Hub/Spawner 入口。

### 质量

- 静态架构合同；
- Headless 原子配置和真实 Spawner 事务；
- 60 分钟确定性规划模拟；
- 正式深渊桌面小队、HUD、真实鼠标击败；
- 低血量降压截图；
- 保存、返回和重载瞬态边界；
- 相邻敌对、枪械、生态和 Runtime Soak；
- Windows Release 实际导出和启动。

## 下一阶段高优先级

### 1. 遭遇奖励与弹药经济

- 统计每种小队平均弹药消耗；
- 小队完成奖励，而不是每个刷怪点无限产出；
- 火药、轻型弹药与霰弹的长期净产出；
- 60 分钟真实经济 Soak；
- 防止利用返回菜单或区块卸载重复领取奖励。

### 2. 结构破坏与掩体反制

- 重击者只破坏低强度临时掩体；
- 射手在视线长期受阻后重新选位；
- 结构破坏与区块更新共享一次批处理 flush；
- 玻璃、栅栏和门的视线语义稳定。

### 3. 方向受击反馈

- 屏幕边缘方向指示；
- 深渊弹和近战来源区分；
- 护甲吸收数字；
- 相机冲击强度设置；
- 可访问性关闭选项。

### 4. 遭遇强度设置

- 休闲、标准和高危三档；
- 只缩放冷却和危险预算，不修改存档；
- 手柄与键盘设置入口；
- 运行中切换的确定性行为；
- 设置损坏回退。

### 5. 长时混合战斗

- 2 射手 + 4 僵尸 + 1 重击者；
- 连续射击、换弹、暂停、保存和恢复；
- 玩家与敌对投射物容量压力；
- 生物死亡、掉落、区块卸载；
- 返回菜单后 ObjectDB、活动弹和遭遇成员归零；
- Windows Release 真实运行 60 分钟。

## 暂不进入下一轮

- 大规模军团；
- 全图共享黑板；
- 导航网格全量重建；
- 网络同步；
- 复杂弹药穿透；
- 永久保存半完成遭遇。

这些内容必须建立在本轮危险预算、原子组队和生命周期门禁持续稳定的基础上。
