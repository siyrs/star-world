# 产品路线图 · Iteration 57

## 本轮完成范围

### 可玩性

- 深渊重击者有限突破临时掩体；
- 临时掩体仅限羊毛和玻璃板族；
- 永久基地不会被破坏；
- 永久掩体阻止隔墙近战伤害；
- 破墙攻击与普通伤害攻击分离；
- 深渊射手在弹道长期受阻后局部换位；
- 关门、开门、栅栏、玻璃板和台阶拥有稳定弹道语义；
- 临时掩体突破与射手换位 HUD。

### 架构

- 纯 `HostileCoverCounterPolicy`；
- 单一 `HostileCoverCounterService`；
- 显式 Hub 生命周期适配；
- 重击者和射手只使用薄子类；
- 最多绑定 32 个精英；
- 初始最多扫描 64 个 Spawner 子节点；
- 单条弹道最多 64 个体素采样；
- 单次攻击最多 2 块、单个重击者最多 12 块；
- 射手每次最多 6 个探针、每目标最多 4 次换位；
- 所有结构破坏共享一次世界 mutation batch；
- 不创建导航网格、全图黑板或第二套存档。

### 质量

- 静态白名单和架构合同；
- Headless 工厂组合、单批次、永久基地和 3600 秒预算；
- 正式深渊重击者突破与零隔墙伤害；
- 正式射手换位与共享 ProjectileRuntime 恢复开火；
- 结构完整性、世界批处理、门、连接方块、敌对远程、枪械和 Runtime Soak；
- 保存、返回和同世界重载生命周期；
- Windows Release 实际导出和启动。

## 下一阶段高优先级

### 1. 方向受击反馈

- 屏幕边缘显示伤害来源方向；
- 近战、深渊弹和环境伤害使用不同图形语义；
- 显示护甲吸收与实际生命伤害；
- 相机冲击强度加入设置；
- 提供完全关闭选项；
- 键鼠、手柄、高 DPI 和超宽屏真实证据。

### 2. 遭遇强度设置

- 休闲、标准和高危三档；
- 只缩放 Encounter 冷却、危险预算和奖励效率窗口；
- 不修改世界存档结构；
- 运行中切换具有确定性；
- 设置损坏时回退到标准；
- 主菜单、暂停菜单和手柄入口一致。

### 3. 长时混合战斗

- 2 名射手、4 名僵尸和 1 名重击者；
- 连续射击、换弹、掩体突破、射手换位、暂停、保存与恢复；
- 玩家与敌对投射物容量压力；
- 生物死亡、掉落和区块卸载；
- 返回菜单后 ObjectDB、活动弹、遭遇成员和 cover counter 全归零；
- Windows Release 真实运行 60 分钟。

### 4. 临时防御物品深化

- 独立的临时路障或沙袋方块；
- 更清晰的耐久/可突破视觉；
- 与羊毛和玻璃板区分材料成本；
- 仍保持严格白名单；
- 不允许敌对生物破坏生产设施和长期建筑。

### 5. 敌对战术反馈整合

- Encounter HUD、奖励 HUD 和 Cover HUD 避免重叠；
- 统一显示小队威胁、换位、破墙与奖励状态；
- F3 增加局部探针、破坏预算和投射物容量；
- 不把瞬态战术信息写入保存。

## 暂不进入下一轮

- 大规模全图建筑破坏；
- 任意低硬度方块自动可破坏；
- 导航网格全量重建；
- 全图共享敌对黑板；
- 敌对生物永久记忆玩家建筑；
- 网络同步；
- 爆炸与复杂穿透。

这些内容必须建立在本轮临时掩体白名单、永久基地保护、单批次结构修改和有限换位持续稳定的基础上。
