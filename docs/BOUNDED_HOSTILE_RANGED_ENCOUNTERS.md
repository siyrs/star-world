# 有界敌对远程遭遇

## 目标

Iteration 54 将敌对战斗从近距离预警攻击推进为可读、可躲、可利用掩体反制的远程遭遇，同时保持现有战斗、存档和运行时边界。

首个远程敌人是 **深渊射手**：

- 只出现在深渊生态；
- 黄昏或夜晚、较深高度才具备生成资格；
- 同时最多两只，权重低于普通僵尸、高于深渊重击者；
- 先显示约 1.1 秒瞄准光束，再发射真实物理深渊弹；
- 玩家可通过移动、打断或实体方块掩体规避；
- 冷却期间进行有界侧移或掩体搜索。

## 原子敌对配置

`HostileAttackRegistry` 不再先清空正式字典再逐条写入。新流程为：

1. 读取完整 JSON；
2. 将全部 profile 标准化到临时字典；
3. 检查身份、类型、距离、时间、投射物和掩体预算；
4. 任一条失败时保留上一份完整注册表；
5. 全部有效才一次替换正式状态。

支持的攻击组合：

- `melee + direct`；
- `ranged + projectile`。

不允许近战 profile 使用投射物，也不允许远程 profile 直接扣血。

## 共享投射物运行时

敌对投射物使用独立的共享 `ProjectileRuntimeService`：

- 正式敌对容量：24；
- 运行时总硬上限：64；
- 速度上限：96；
- 距离上限：256；
- 寿命上限：12 秒；
- 重力上限：64；
- 一个 `_physics_process()`；
- 每个活动投射物每帧最多一次线段射线；
- 无逐投射物 Timer、线程或世界实体扫描；
- 命中、超时、世界切换和关闭时确定性释放。

玩家箭矢和敌对深渊弹复用同一实现，但使用两个独立容量池，避免大量敌对弹丸占满玩家箭矢额度。

## 视线与掩体

深渊射手的视线每 0.16 秒最多刷新一次。

冷却期间最多检查六个掩体方向，每个候选最多进行：

1. 地面支撑射线；
2. 到候选点的通路射线；
3. 玩家到候选点的遮挡射线。

没有导航全图扫描、路径洪泛或 `get_nodes_in_group()` 热路径。

## 按攻击者受击冷却

旧实现只有一个全局敌对受击冷却：任意敌人命中后，所有其他敌人都会在约 4.5 秒内失去伤害能力。

现在玩家维护最多 32 个攻击者冷却：

- 同一攻击者重复命中被抑制；
- 不同攻击者可形成真实协同压力；
- 超过容量时淘汰剩余时间最短的条目；
- 世界进入、重生和过期时确定性清理；
- 旧 `_hostile_damage_cooldown_remaining` 仅保留为兼容诊断投影。

## 存档边界

持久化：

- 玩家生命、装备和已有世界数据；
- 生物与生态的权威配置文件。

不持久化：

- 活动敌对投射物；
- 瞄准进度；
- 视线缓存；
- 掩体候选；
- 侧移方向；
- 攻击者冷却字典。

世界切换和返回菜单会清空所有上述瞬态状态。
