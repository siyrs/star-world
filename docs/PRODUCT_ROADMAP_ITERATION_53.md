# Product Roadmap · Iteration 53 · Bounded Firearms

## 本轮交付

把已经成熟的弓箭远程架构向前推进为完整枪械战斗闭环，同时保持《星的世界》的像素生存定位与工程边界。

### 可玩内容

- 星火手枪：稳定半自动、8 发弹匣；
- 拓荒卡宾枪：有界全自动、24 发弹匣；
- 裂岩霰弹枪：泵动节奏、7 弹丸聚合；
- 火药、轻型弹药和霰弹制作；
- 键盘 `R` 与手柄左肩键换弹；
- 弹匣、备用弹、射击恢复和换弹 HUD；
- 手枪、卡宾枪与霰弹枪独立第一人称像素模型；
- 后坐力与命中反馈；
- 弹匣、备用弹和耐久保存重载。

### 工程推进

- 物品与配方支持多个扩展文件的原子 staged merge；
- 弓箭与枪械共享 RangedWeaponRegistry；
- 12 射线、128 格的无节点 HitscanRuntime；
- 霰弹按目标聚合，只调用一次 CombatService；
- 弹匣属于装备实例 metadata；
- 换弹完成时才扣备用弹，不提前扣；
- 主手装备优先的第一人称视图模型；
- 新旧功能全部进入固定 GitHub Actions 门禁。

## 下一轮候选

在本轮稳定后，可继续选择：

1. 敌对远程单位与掩体行为，继续复用 HitscanRuntime/ProjectileRuntime；
2. 枪械配件，但必须保持 profile 有界且不动态执行脚本；
3. 弹药稀缺与世界掉落平衡；
4. 枪械音效与粒子反馈的共享池化运行时；
5. 武器快捷切换与装备比较 UI；
6. 高难地图中的远程敌对遭遇。

## 不进入本轮

- 现实武器制造参数或现实弹药配方；
- 网络多人同步；
- 逐弹丸刚体节点；
- 弹道穿墙或复杂材质穿透；
- 第二背包、第二伤害服务或第二存档格式；
- 无界射速、无界弹丸或无界命中距离。

## 完成定义

- 功能、静态合同、领域测试、真实物理和正式桌面全部完成；
- 弓箭、控制器、装备、背包、视图模型和 Runtime Soak 相邻门禁不回退；
- 权威 Runtime、桌面矩阵和 Windows Release 通过；
- 固定最终 SHA 无失败、无排队、无运行中工作流；
- PR 转 Ready 后按固定 SHA squash 合入 `master`。
