# Changelog

## 1.3.0 - 2026-08-02

### 玩法

- **熔岩成为危险地形**：接触熔岩持续灼烧（每 0.5s 4 点伤害，离开即停，长时间浸泡致死并可重生）——不再与水体等同（BUG-LAVA-001）。
- 五张正式地图（星辰大陆/荒漠遗迹/极寒冰原/天空群岛/深渊世界）完成深度验收旅程：河流/冰下/熔岩水域、地下矿路、遗迹/浮岛地形、夜间遭遇、勘探里程碑、死亡复活、持久化与重复进入。

### 稳定性与性能

- 修复 4 个测试出口的 ObjectDB/Resource 泄漏（BUG-LEAK-001）：未入树的 Node 实例、音频流缓存均正确释放，全量回归零泄漏。
- 新增 13 场景性能采集（菜单/五图出生/移动压力/重复加载/设置变更）+ 外部进程内存采样；30 分钟跨五图长稳 soak（291 循环，内存增长 1.9%）。
- 极端输入（120 键+90 鼠标突发）、暂停/恢复、UI 缩放、快速进入/存档/返回稳定性套件。

### 存读档与数据安全

- 存读档矩阵：手动存档往返、覆盖写代际（`.bak` 保留上一代）、多世界独立、v1→v2 旧档迁移。
- 目录/存档类回归现在正确区分真实用户世界与测试数据，QA 全程不触碰用户世界。

### UI 与无障碍

- 全部交互按钮状态（normal/hover/pressed/focus）对比度 ≥ 4.5:1；键盘导航、控制器焦点、高 DPI 缩放验证（QA-003 独立复测 279 项检查）。

### 自动化

- 全量回归 113/113 通过；fresh Windows export smoke 16/16；五图深度旅程 141 项检查。
- 新增可重复脚本：性能采集、长稳 soak、QA-003 独立复测、存读档/水域/熔岩/稳定性矩阵。
