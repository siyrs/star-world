# UI Accessibility Scaling and Controller Focus

## 目标

本轮为《星的世界》补齐高 DPI 与控制器焦点合同。它解决四个此前没有正式状态所有者的问题：

1. 高 DPI 显示器只能依赖操作系统缩放，游戏内无法选择稳定 UI 比例；
2. 主菜单和游戏内 Overlay 在鼠标、键盘与手柄切换后可能保留错误焦点；
3. Windows 在高 DPI 缩放、菜单显隐和 Overlay 动画期间可能生成合成 MouseMotion，错误抢走控制器模式；
4. 既有 1024×576 / 1280×720 测试没有覆盖 2560×1440、150% UI 和真实 D-Pad 焦点旅程。

## 唯一状态所有者

`UiAccessibilityService` 是会话级唯一状态所有者，负责：

- 当前输入模式：`mouse`、`keyboard`、`controller`；
- 当前 UI 比例：80%、100%、125%、150%；
- 输入模式、比例、转场保护和忽略 MouseMotion 的精确计数；
- 将比例投影到 `ThemeDB.fallback_base_scale`；
- 向主菜单、游戏内 Overlay 和运行诊断提供只读事实。

它不拥有：

- 世界状态；
- 玩家状态；
- Overlay 类型；
- 当前焦点节点；
- 存档写入。

## 设置合同

`GameSettingsPolicy` 将 `ui_scale` 纳入严格白名单。允许值固定为：

```text
0.80
1.00
1.25
1.50
```

非法类型、非有限值和任意中间值通过最近邻规则确定性归一化。距离相同时选择较小比例，避免异常配置把 UI 意外放大。

`ui_scale` 属于本地用户设置，不进入 `world.json`，也不改变 Seed、地图、角色或玩法状态。

## 输入模式合同

- 有效 Joypad Button 或超过 0.55 的摇杆输入切换到 `controller`；
- 小于阈值的摇杆漂移不改变模式；
- 有意义的鼠标移动或鼠标按下切换到 `mouse`；
- 非重复按键切换到 `keyboard`。

鼠标模式释放本项目 UI 持有的键盘焦点；键盘或控制器模式会在当前可见工作区恢复一个确定性的可交互控件。

### MouseMotion 滞回

为避免 Windows/ANGLE 在高 DPI 重布局时发送的合成移动抢走手柄焦点，服务拥有两层严格且有界的 MouseMotion-only 保护：

- 控制器输入后 350ms 内忽略 MouseMotion；
- Theme 缩放、主菜单显隐或 Overlay 切换后 750ms 内忽略 MouseMotion。

鼠标按键永远不受保护窗口影响，会立即切换到 `mouse`。键盘和控制器输入也始终即时生效。保护只记录标量截止时间和精确计数，不创建 Timer、不排队事件、不修改输入本身。

## 焦点所有权

### 主菜单

- 显示主菜单时聚焦“继续游戏”；
- D-Pad/方向键在六个命令内移动；
- 打开地图、存档或设置后，焦点进入首个可交互控件；
- 返回后恢复主操作；
- 鼠标按键或保护窗口外的真实移动释放焦点；
- 主菜单显隐会开启一次有界转场保护。

### 游戏内 Overlay

- 背包、合成、机器、修理、探索日志、暂停和死亡界面沿用同一焦点恢复规则；
- HUD 本身不抢焦点；
- 关闭 Overlay 后不保留隐藏控件焦点；
- Overlay 打开等待共享 `PanelAnimator.DURATION`，随后最多两次确认焦点进入当前工作区；
- 每次成功或失败都有信号和精确累计；
- 输入模式只控制焦点所有权，不修改 Overlay 状态。

## 真实验收

专项真实窗口旅程使用 2560×1440 产品窗口并完成：

1. 真实鼠标打开设置；
2. 选择 150% UI；
3. 真实点击“保存并应用”；
4. 验证设置、服务和 ThemeDB 三处一致；
5. 保存高 DPI 设置截图；
6. 使用真实 Joypad D-Pad 将焦点移动到“创建新世界”；
7. 使用 Joypad A 打开创建世界；
8. 使用 Joypad B 返回主菜单；
9. 隐藏主菜单，注入真实 MouseMotion 并验证转场保护阻止模式误切换；
10. 打开游戏内背包并等待正式焦点成功信号；
11. 使用鼠标按键立即接管，再使用手柄恢复；
12. 输出第二张焦点截图和包含保护计数的 JSON 报告。

## 预算与非目标

- 比例选项固定四档，不允许无限连续缩放；
- 输入模式只保留一个当前值、时间戳和标量计数；
- 控制器保护固定 350ms，UI 转场保护固定 750ms；
- 不轮询设备列表；
- 不创建 Timer 节点；
- 不引入第二套主题；
- 本轮只保证 UI 导航焦点，不承诺完整手柄移动、战斗和快捷栏映射。
