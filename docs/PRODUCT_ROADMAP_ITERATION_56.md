# 产品路线图 · Iteration 56

## 本轮完成范围

### 可玩性

- 小队全员击败奖励；
- 夜行巡猎、深渊游猎和深渊突袭补给；
- 基础奖励与高效率加成；
- 当前小队真实弹药消耗；
- 净弹药收益提示；
- 满背包待领取与自动重试；
- 卸载成员不发放奖励。

### 架构

- 原子 Encounter Reward Registry；
- Reward Service 只观察 Director、成员死亡、RangedCombat 与 Inventory；
- 2 个活动账本；
- 8 个待领取奖励；
- 256 条本世界 claim history；
- 奖励通过现有 Inventory 原子事务进入权威存档；
- 不新增奖励存档 schema。

### 质量

- 最后一击与 shot_fired 时序反回归；
- 重复 completion 幂等；
- 两队 miss 不双重计费；
- 满背包零部分写入；
- 自动重试；
- 3600 秒、80 场确定性经济模拟；
- 正式深渊桌面两场战斗、奖励 HUD 和待领取截图；
- 保存、返回和重载瞬态边界；
- Windows Release 实际导出和启动。

## 下一阶段高优先级

### 1. 结构破坏与掩体反制

- 重击者只破坏低强度临时掩体；
- 射手长期失去视线后重新选位；
- 结构变更与区块网格共享一次批处理 flush；
- 玻璃、栅栏、门和半砖视线语义；
- 防止怪物无限拆除玩家永久基地。

### 2. 方向受击反馈

- 屏幕边缘方向指示；
- 近战、深渊弹和环境伤害来源区分；
- 护甲吸收与最终伤害数字；
- 相机冲击强度设置；
- 可访问性关闭选项。

### 3. 遭遇强度设置

- 休闲、标准和高危三档；
- 只缩放 Encounter 冷却和危险预算；
- 不修改存档内容；
- 键盘、鼠标和手柄设置入口；
- 运行中切换与损坏设置回退。

### 4. 弹药制造与掉落再平衡

- 比较奖励弹药、成员掉落和工作台制造成本；
- 统计手枪、卡宾枪和霰弹枪每场平均成本；
- 防止低风险巡猎队成为无限弹药农场；
- 深层地图提高火药、而不是成品弹药占比；
- 不同难度下保持长期净产出可控。

### 5. 长时混合战斗 Release Soak

- 2 射手 + 4 僵尸 + 1 重击者；
- 连续开火、换弹、建造掩体、暂停和保存；
- 玩家与敌对投射物容量压力；
- 奖励 pending 与自动领取；
- 生物死亡、掉落、区块卸载；
- 返回菜单后 ObjectDB、弹丸、遭遇成员和经济账本全部归零；
- Windows Release 真实运行 60 分钟。

## 暂不进入下一轮

- 永久保存半完成遭遇；
- 跨世界共享奖励队列；
- 大规模敌人军团；
- 全图共享黑板；
- 网络同步；
- 真实货币或在线经济。

后续功能必须继续复用当前危险预算、原子背包和世界生命周期边界。
