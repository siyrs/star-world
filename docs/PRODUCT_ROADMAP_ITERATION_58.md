## 架构决定

- `world.json` 保持唯一权威；`catalog.pending` 只表示 sidecar 可能落后。
- 标记存在时宁可执行预算内权威读取，也不接受可能陈旧的 catalog。
- 标记、自动保存调度和检查点诊断均不进入世界存档。
- 长期资格通过组合现有预算证明，不增加平行 Timer、全世界扫描或第二运行时。
- 高 DPI 证据使用 2× 逻辑缩放模拟；真实设备体验仍由 E4-H 负责。

## 验收条件

- 新专项工作流全绿；
- 所有受影响的既有永久门禁全绿；
- Windows Release 导出与启动 smoke 全绿；
- PR 固定 head SHA 上无待处理评审线程；
- 合并后 `master` push 门禁再次通过。

## 后续

仓库内下一步只应继续做可重复的故障注入、真实 Release 计时和证据工具。不得把外部硬件/人工资格伪装成自动化完成。
