# Product Roadmap · Iteration 52 · 有界远程战斗

## 本轮产品跃迁

把现有近战生存闭环扩展为第一套可制作、可装备、可操作、可命中、可保存的远程战斗：

- 工作台制作猎弓；
- 工作台批量制作箭矢；
- 猎弓进入现有主手装备槽；
- 鼠标左键与手柄右扳机长按蓄力、松开发射；
- 射程、速度、重力、伤害和冷却数据驱动；
- 真实飞行箭命中现有生物；
- 复用目标防御、击退、受击硬直、击败与战斗反馈；
- 弹药和耐久进入现有存档，飞行状态保持瞬态。

## 完成标准

- 注册表和配方扩展原子加载，重复 ID 不静默覆盖；
- 单一投射物运行时，活动上限 64；
- 没有 per-projectile Timer、第二伤害服务或第二存档域；
- 蓄力不足、取消、无箭和容量满均为零消耗；
- 正式桌面同时验证真实鼠标和真实手柄扳机；
- 权威保存重载保持箭矢和猎弓耐久；
- 截图、JSON 和日志作为 14 天 CI Artifact；
- 全仓 Runtime、桌面矩阵和 Windows Release 全绿后才合入 master。

## 后续扩展接口

本轮只交付一把猎弓和一种箭矢，但 profile 已允许后续增加：

- 不同弓弩的蓄力、速度、重力和冷却；
- 特殊箭的伤害或命中能力；
- 敌对生物远程攻击；
- Boss 弱点与投射物抗性；
- 音效、轨迹和命中特效。

后续内容必须继续复用同一投射物预算、CombatService 和保存边界。
