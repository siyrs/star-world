# 地图与内容覆盖矩阵（证据分级版）

五个正式地图是同一 `game.tscn` 下由 `data/map_profiles.json` 驱动的程序化世界 Profile，不是五个独立场景。当前源码没有传统主线、结算或通关条件，因此“通关”只能标记为不适用，不能用直接调用函数或修改存档伪造。

## 证据等级

- **E0**：静态资源/配置存在。
- **E1**：生成器、注册表或纯策略验证。
- **E2**：真实生产场景中的服务/状态验证。
- **E3**：正式输入动作驱动真实玩家、物理或交互。
- **E4**：最终导出程序的桌面视觉/录屏与人工体验复审。

> 重要：E0/E1/E2 通过不等于“完整探索”。完整探索至少需要 E3 的区域、连续路线、边界、兴趣点与特殊环境矩阵，并对关键体验提供 E4 证据。

## 原“深度旅程”可支持的结论

`tests/qa/profile_deep_journey_regression.gd` 的 141 checks 仍有价值，但应准确描述为：

- 五个 Profile 可通过真实菜单创建并进入；
- 固定 Seed 的生成器特征与部分领域服务合同成立；
- 死亡后真实“重生”按钮可恢复；
- Profile/Seed 可保存并读取；
- 同一 Profile 可重复创建和返回菜单；
- 若干领域服务可被调用。

它不能单独支持：

- 玩家已经走遍地图；
- 玩家能够通过正常路线到达全部兴趣点；
- 全部空气墙、穿模、水下、地下和高空问题不存在；
- 全部玩法已经通过真实输入完成；
- 商用品质已达标。

## 当前关闭条件

地图覆盖矩阵只有在以下证据齐备后才可把某一地图标记为“完整探索”：

1. 至少 6 个区域的 E3 玩家输入与真实物理门禁通过；
2. 出生点到关键区域的连续正常玩家路线通过；
3. 地图边界、空气墙、狭窄区、掉图、卡位和恢复矩阵通过；
4. 该地图实际存在的水域、地下、高空、传送与兴趣点全部有 E3 证据；
5. 最终 Windows 导出程序有 E4 截图/录屏并完成独立复审；
6. 发现的问题已修复并在同一路线回归。
