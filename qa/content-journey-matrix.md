# 正式内容玩家闭环矩阵

状态：**持续复审中；`BUG-QA-CONTENT-001` 仍未关闭**  
复审基线：`master@74545b17125a77d914fc53b5319c6055fae4a04d`  
本轮分支：`agent/player-crafting-closed-loop-v2`

本矩阵用于回答一个严格问题：玩家是否通过正式输入完成了该内容的成功、失败、保存和重载闭环。它不再把“服务已挂载”“注册表非空”“测试直接调用服务成功”写成“玩家已经完整体验”。

## 证据等级

- **E0**：静态资源、配方、配置或场景存在。
- **E1**：纯策略、注册表、生成器或离线数据验证。
- **E2**：真实运行时中的服务、状态或事务验证，但不要求玩家正式输入。
- **E3**：生产场景、正式输入、真实物理/UI/交互驱动的玩家旅程。
- **E4**：最终导出的 Windows 程序完成真实桌面操作、截图/录屏和独立人工体验复审。

> 当前多数 desktop acceptance 使用真实生产场景与桌面输入，属于 E3 并附带视觉证据；它们不是最终导出程序的人工验收，不能自动升级成 E4。

## 本轮合成闭环可支持的结论

本轮完成后可以准确声明：

- 玩家可以通过真实 C 键进入随身合成；
- 玩家可以瞄准真实世界中的工作台并通过右键进入工作台合成；
- 配方按钮具有不依赖中文文本和排列顺序的稳定身份；
- 多步材料转换和工作台专属物品由真实鼠标按钮完成；
- 禁用按钮不会修改背包；
- 已启用但服务条件在点击前变化时，事务失败且不产生部分消耗；
- 成功和失败都有可见、可审计的配方级反馈；
- 合成后的精确背包可保存、返回菜单并完整重载；
- 失败产物不会在重载后出现，消耗材料不会复活。

它不能单独支持：

- 所有 72+ 配方均已由玩家逐一制作；
- 控制器、触摸或所有分辨率均完成同等旅程；
- 最终 Windows 导出程序已经完成 E4 人工体验；
- 其他内容领域已经自动因合成闭环而达到发布标准。
