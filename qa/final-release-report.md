## 1. 复审结论

当前仓库已经具备较强的工程基础，以下证据仍然有效：

- Windows fresh export 与 release smoke 已有通过记录；
- 五个正式 Profile 均能通过正常菜单创建并进入；
- 存档、覆盖、多世界、迁移、死亡与重生已有自动化；
- 河流、冰下水与熔岩状态生命周期已有专项测试；
- UI、设置、输入上下文、运行日志与资源泄漏已有专项门禁；
- 已采集 FPS、帧时间、内存、加载时间与 30 分钟脚本化 soak；
- 基线全量自动化曾记录 `113/113 EXIT 0`。

但以下原发布结论缺少足够证据：

1. **“五张地图完整探索”不成立。** 现有 `profile_deep_journey_regression.gd` 大量使用离线生成器扫描、直接查询服务快照或调用测试入口；它能证明规则和服务存在，不能证明玩家实际走过地图。
2. **“全部正式内容已覆盖”不成立。** “服务已挂载”“快照可读取”“配方列表非空”不能替代真实合成、真实加工、真实战斗、真实饲养、真实休息、真实建造链和失败/恢复路径。
3. **“空气墙、碰撞、穿模、掉图已系统检查”只能判定为部分完成。** 接缝高度连续和 Y 下限恢复是有效的局部证据，但没有形成跨地图、跨区域、玩家输入驱动的路线覆盖。
4. **“推荐发布”证据不足。** 自动化全绿只表示已定义断言全部通过，不表示未定义的体验问题不存在。
5. **性能结论仍需收口。** 已记录天空群岛 1% Low 最低约 16 FPS、部分出生阶段 p95 帧时约 40ms；在未定义目标硬件与帧率门槛前，不能直接判定商用品质达标。

因此当前发布建议为：**暂缓正式商业发布，继续迭代与真实体验验收。**

## 2. 证据等级合同

后续所有 QA 文档与发布结论必须使用以下等级，不得跨级推断：

| 等级 | 证据类型 | 可以证明 | 不能证明 |
|---|---|---|---|
| E0 | 静态文件、注册表、配置检查 | 内容被声明、资源可加载 | 内容可玩或体验正常 |
| E1 | 纯策略、生成器、离线数据扫描 | 规则确定性、地图特征可能存在 | 玩家能到达、碰撞正确、视觉合理 |
| E2 | 真实生产场景中的服务/状态调用 | 运行时服务可工作、状态可保存 | 玩家通过正常输入完成了流程 |
| E3 | 真实场景 + 正式输入动作 + 真实物理/交互 | 玩家可在被覆盖路径实际操作 | 未覆盖区域、完整视觉体验、长期主观手感 |
| E4 | 最终导出程序的桌面旅程、截图/录屏与人工复审 | 可见布局、反馈、连贯性和主观体验 | 所有随机 Seed 与无限程序化空间 |

“完整探索”至少需要 E3 的区域/路线/兴趣点覆盖矩阵，并对关键视觉与手感提供 E4 证据。单独的 E0/E1/E2 不得标记为完整探索。

## 3. 本轮新增纠偏门禁

新增：`tests/qa/player_driven_regional_traversal_regression.gd`

它对五个正式 Profile 执行：

- 加载真实 `game.tscn`、真实世界、真实玩家和正式输入上下文；
- 在固定 Seed 下发现相隔较远的安全区域；
- 每个 Profile 至少覆盖 6 个唯一 Chunk；
- 在每个区域同步加载真实碰撞；
- 使用 `Input.action_press()` 驱动正式 WASD 行为；
- 验证真实 `CharacterBody3D` 能移动、不会立即掉图或处于无效坐标；
- 输出逐地图区域、Chunk、动作和位移证据。

该测试允许在区域之间使用有界 QA 快速移动，但每个区域内的通过条件必须来自正式输入和物理移动。它补齐的是“区域级玩家可移动性”，**仍不等于整张程序化地图的连续全遍历**。

## 5. 当前阻塞问题

### BUG-QA-COVERAGE-001 — P1 — 地图覆盖结论失真

- 复现：阅读 `profile_deep_journey_regression.gd` 与原地图矩阵；“完整探索”主要由生成器扫描、服务快照与直接测试调用支撑。
- 根因：没有证据等级合同，把 E1/E2 结果提升成 E3/E4 结论。
- 本轮修复：新增玩家输入驱动的区域穿行门禁，并重写发布/地图矩阵。
- 关闭条件：五图区域门禁通过；再补关键连续路线、边界、地下、水域、兴趣点与最终导出程序的 E4 证据。

### BUG-QA-CONTENT-001 — P1 — 内容矩阵存在假绿

- 复现：原内容矩阵以“农业服务挂载”“熔炉服务挂载”“探索快照可读取”等条件判定内容已测试。
- 根因：领域合同测试与玩家端到端体验测试未分层。
- 关闭条件：为合成、机器、农业、畜牧、休息、建造、近战、远程、枪械、敌对遭遇、奖励分别建立真实输入驱动的成功/失败/保存/重载旅程。

### BUG-QA-VISUAL-001 — P1 — 全地图视觉与手感证据不足

- 复现：现有截图主要覆盖 UI、出生点或单一场景状态，没有证明全部关键区域、空气墙、水下、地下、高空和边界的视觉一致性。
- 关闭条件：最终 Windows 导出程序完成关键路线录屏/截图清单，并由独立复审逐项签字。

### BUG-PERF-002 — P1 — 商用性能目标未闭环

- 当前证据：天空群岛 1% Low 最低约 16 FPS；部分出生阶段 p95 帧时约 40ms。
- 根因状态：尚未完成目标硬件分级、热点采样和优化后复测。
- 关闭条件：定义最低/推荐硬件及 30/60 FPS 门槛；定位天空群岛与出生流式加载热点；优化后提供同场景前后对比。
