## 1. 当前复审结论

仓库已经具备较强的工程和自动化基础：

- Windows 导出与 release smoke 可重复通过；
- 五个正式 Profile 均可通过正常入口创建和进入；
- 五图真实玩家区域移动门禁已通过，每图至少覆盖 6 个唯一 Chunk；
- 存档、覆盖、多世界、迁移、死亡与重生已有专项自动化；
- 河流、冰下水和熔岩状态生命周期已有专项测试；
- UI、设置、输入上下文、运行日志、资源泄漏和长时循环已有门禁；
- 深渊蛮兵与射手具备有界、可审计且不会隔墙伤害玩家的临时掩体反制；
- 性能指标已纠偏为真实帧时口径；
- 天空群岛柱级重复计算热点已优化，固定基准约 2.97× 加速且方块输出完全一致；
- **合成子领域已经完成真实玩家成功、失败、保存、返回菜单和完整重载闭环**；
- 背包保存结构已经规范化，普通堆叠不会在重载后被无意义地注入空 metadata。

但当前仍缺少足够证据支持商业正式发布：

1. **五张地图尚未完成连续路线级探索。** 现有区域门禁能够证明多个真实区域可移动，但区域之间允许有界 QA 快速转移，不能替代玩家从出生点沿正常路线连续到达关键区域。
2. **全部正式内容尚未形成玩家闭环。** 合成已完成 E3 闭环；机器、农业、畜牧、休息、修理、探索和战斗仍需按领域补齐失败、保存和完整重载证据。
3. **最终 Windows 导出程序的全地图视觉与手感复审尚未完成。** 当前截图和桌面旅程覆盖多个功能页面与局部世界状态，但没有覆盖全部关键区域、边界、地下、水域和高空路线。
4. **目标硬件性能尚未验收。** 指标定义和一个明确热点已经闭环，但 GitHub 托管 Runner 使用 ANGLE + Microsoft Basic Render Driver，只能验证采集链路，不能代表玩家 GPU。
5. **严格长稳门槛仍未完成。** 30 分钟高密度循环和短时 runtime soak 有效，但尚未达到严格 120 分钟目标硬件门槛。

因此当前建议仍为：**继续内部测试、封闭测试和功能迭代，暂缓商业正式发布。**

## 2. 证据等级合同

所有 QA 文档和发布结论必须使用以下等级，不得跨级推断：

| 等级 | 证据类型 | 可以证明 | 不能证明 |
|---|---|---|---|
| E0 | 静态文件、注册表、配置检查 | 内容被声明、资源可加载 | 内容可玩或体验正常 |
| E1 | 纯策略、生成器、离线数据扫描 | 规则确定性、地图特征可能存在 | 玩家能到达、碰撞正确、视觉合理 |
| E2 | 真实生产场景中的服务/状态调用 | 运行时服务可工作、状态可保存 | 玩家通过正常输入完成了流程 |
| E3 | 真实场景 + 正式输入动作 + 真实物理/交互 | 玩家可在被覆盖路径实际操作 | 未覆盖区域、完整视觉体验、长期主观手感 |
| E4 | 最终导出程序的桌面旅程、截图/录屏与人工复审 | 可见布局、反馈、连贯性和主观体验 | 所有随机 Seed 与无限程序化空间 |

“完整探索”至少需要 E3 的区域、连续路线、边界、兴趣点和特殊环境覆盖，并对关键视觉与手感提供 E4 证据。单独的 E0/E1/E2 不得标记为完整探索。

## 3. 已完成的重要纠偏与迭代

### 3.1 五图玩家区域穿行

`tests/qa/player_driven_regional_traversal_regression.gd` 对五个正式 Profile：

- 加载真实 `game.tscn`、真实世界、真实玩家和正式输入上下文；
- 在固定 Seed 下选择相隔较远的安全区域；
- 每个 Profile 至少覆盖 6 个唯一 Chunk；
- 同步加载真实碰撞；
- 使用 `Input.action_press()` 驱动正式 WASD；
- 验证真实 `CharacterBody3D` 能移动，不会立即掉图或进入无效坐标。

该门禁证明“区域级真实玩家可移动性”，仍不等于整张程序化地图的连续全遍历。

### 3.2 敌对临时掩体反制

PR #94 已完成：

- 蛮兵只可拆玩家明确放置的临时羊毛和易碎玻璃；
- 石头、木板、门、围栏、台阶、机器和生成地形保持受保护；
- 单次攻击最多拆 2 块，单只蛮兵生命周期最多拆 12 块；
- 永久墙、预算耗尽和世界修改失败都会阻止同帧伤害；
- 射手换位拒绝水、熔岩、仙人掌、无支撑位置和异常高差；
- 搜索、尝试、路线采样和运行时绑定均有硬上限；
- 专项回归验证生产蛮兵不会在任何失败路径中隔墙伤害玩家。

### 3.3 性能指标纠偏

`BUG-PERF-METRIC-001` 已修复并通过 QA：

- 旧版 `1% Low FPS` 是对 `Engine.get_frames_per_second()` 滚动显示值取分位，不是逐帧 1% Low；
- 新版平均 FPS和 1% Low 均由同一组真实 frame time 计算；
- 报告新增 p95、p99、最小/最大帧时以及 30/60 FPS 帧预算超限比例；
- 滚动 FPS 只保留为 diagnostic；
- 报告升级为 schema 2 / `frame-time-tail-v2`；
- 确定性夹具和五图桌面报告均验证数据内部一致性。

旧性能报告中的逐帧 `frame_ms`、p95、p99、加载和内存数据仍有历史参考价值；旧版“平均 FPS”和“1% Low FPS”不再用于发布判定。

### 3.4 生成器柱缓存优化

`BUG-PERF-COLUMN-001` 已修复并通过 QA：

- 缓存 Profile+Seed 下不可变的地表高度和天空岛强度；
- 默认容量 8,192，硬上限 32,768；
- 确定性 FIFO 淘汰和顺序账本压缩；
- Profile/Seed 重配时强制失效；
- 玩家覆盖和其他可变世界状态不进入缓存；
- streaming diagnostics 暴露命中、未命中、淘汰、容量和真实计算次数。

固定 `sky_islands / Seed 112358 / 16×16×64` 同进程基准：

| 指标 | 缓存关闭 | 缓存开启 | 结果 |
|---|---:|---:|---:|
| 生成耗时 | 345,428 μs | 116,287 μs | 约 2.97× 加速 |
| 地表高度真实计算 | 16,424 | 256 | 约 64.2× 减少 |
| 天空岛强度真实计算 | 17,418 | 256 | 约 68.0× 减少 |
| 16,384 方块差异 | — | 0 | 完全一致 |

五个正式 Profile 均已执行缓存开关前后的方块输出逐项对比。

### 3.5 合成玩家闭环

`BUG-QA-CONTENT-CRAFT-001` 已修复并通过 QA。新的生产场景桌面旅程包含：

1. 真实 `C` 键打开随身合成；
2. 无材料配方保持可见并禁用，鼠标点击不改变背包；
3. 真实鼠标按钮完成两次原木→木板、木板→木棍和工作台制作；
4. `Esc` 关闭面板并恢复游戏输入；
5. 真实中心射线命中世界中的工作台；
6. 真实右键打开工作台工位；
7. 目标配方若位于滚动区域外，先滚动到可见范围并验证点击中心位于 viewport，再发送真实鼠标事件；
8. 真实按钮制作木剑；
9. 一个已渲染为启用的木镐按钮在点击前遇到工位条件变化，服务拒绝事务、背包零修改、产物为零并显示明确错误；
10. 合成后的精确背包进入权威保存，返回菜单后完整重载；
11. 工作台、木剑和剩余木棍精确恢复，已消耗材料和失败木镐不会复活；
12. 重载后重新打开面板，不保留旧成功/失败提示。

产品改进：

- 配方按钮提供稳定 `recipe_id`、`output_item_id` 和 `station`，不再依赖中文文本或列表顺序；
- 面板订阅生产 `craft_succeeded/craft_failed` 信号；
- 玩家可看到配方级成功或失败反馈；
- 满背包、无效产物、材料/工位不符和服务不可用均有明确文案。

专项证据：

- 合成桌面：**78 checks**；
- canonical 背包往返：13 checks；
- 背包事务：27 checks；
- integration：34 checks；
- input interaction：33 checks；
- block interaction：34 checks；
- 五图 profile journey：57 checks；
- 切石机、畜牧、牧场产物和修理四项相邻桌面旅程全部复跑通过。

这使合成子领域从 E2 提升为 **E3 成功/失败/保存/完整重载闭环**。它不等于全部配方逐一人工制作，也不等于其他内容领域已经自动闭环。

### 3.6 背包 canonical 保存结构

`BUG-INV-CANONICAL-001` 已修复并通过 QA：

- 普通无 metadata 堆叠在保存时不含 `metadata` 字段；
- 重载不再无条件补入空字典；
- 旧存档中的空 metadata 会在下一次保存时自动规范化；
- 错误类型的可选 metadata 被忽略，不会污染运行时状态；
- 其他槽位中的有效耐久和自定义名称仍会保留；
- `serialize→deserialize→serialize` 可以保持精确 canonical 结构相等。

该修复避免了“数量正确但结构漂移”的假精确重载。

## 7. 当前推荐

现有自动化、区域移动、掩体反制、生成器优化和合成闭环均为有效工程进展，但不能单独证明“全部地图已玩完、全部内容已体验、可以商业发布”。
