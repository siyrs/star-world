## 1. 证据等级

- **E0**：静态文件、注册表、配置和架构合同。
- **E1**：纯策略、生成器和确定性单元回归。
- **E2**：真实服务、领域状态和序列化运行时回归。
- **E3**：生产场景、真实输入、真实物理/UI、成功与失败、保存、返回菜单和完整重载。
- **E4-A**：最终导出程序上的自动路线、截图、帧时、内存和无 fatal 证据。
- **E4-H**：独立人员在明确的最低/推荐硬件上完成视觉、手感、可理解性和长时间体验签字。

E0–E3 或 E4-A 不能自动升级成 E4-H；无限程序化世界的有界路线也不等于“完整探索全部地图”。

## 3. 缺陷与阻塞状态

### BUG-QA-COVERAGE-001 — qa-passed

旧问题是五张地图没有从生产出生点出发的连续玩家路线，服务快照和区域传送被错误当作完整地图证据。PR #100 已用正式移动/跳跃输入、真实 `CharacterBody3D` 和实时 Chunk 碰撞完成五图有界连续路线；PR #101 将同一合同放入最终导出程序，并拒绝任何出生后坐标写入。

关闭此缺陷只表示**发布关键有界路线已通过**，不表示无限世界或全部随机 Seed 已完整走遍。

### BUG-QA-CONTENT-001 — qa-passed

此前缺少畜牧、牧场、农业、床位、探索、教程和建造/采矿的统一 E3 闭环。PR #96–#100 已关闭合成、修理、机器及五个剩余领域；PR #101 补齐教程跨会话中断/完成和建造/采矿失败守恒与完整重载。`qa/content-journey-matrix.md` 现在按统一定义记录正式入口、失败原子性、权威保存、菜单返回和完整重载。

### BUG-QA-EXPORT-ROUTE-001 — qa-passed

旧 `ReleaseSmokeRunner` 只运行星辰大陆，并在 soak 和截图阶段直接写 `player.global_position`，不能证明最终程序通过正常操作移动。当前：

- `ProductionRouteProbe` 位于 `src/diagnostics`，可进入最终 PCK；
- 五图均可由 CLI 指定 Profile/Seed；
- 路线只使用生产 `Input`、真实物理和已加载体素碰撞；
- 报告记录 `transport_after_spawn=false`、`player_transform_writes=0`；
- 最终截图在真实路线终点采集，不再回传出生点；
- 一个已验证的 EXE/PCK 被复用完成五图矩阵；
- 诊断候选世界加载 canonical 已完成教程状态，最终截图不会反复被新手引导遮挡；真实新玩家教程仍由独立 E3 旅程验证。

### BUG-QA-SOAK-TRANSPORT-001 — qa-passed

旧长稳测试每隔固定帧直接改玩家坐标，制造的流式压力不代表玩家真实移动。当前长稳循环复用生产路线探针，每个周期记录路线、Profile、Chunk、帧时和无传送合同；报告 schema 升级为 2。托管参考除了满足时间预算，还必须至少完成 5 个循环并覆盖五张正式地图各一次。

### BUG-QA-VISUAL-EVIDENCE-001 — qa-passed

旧最终包截图来自空 `experience` 的合成世界，因此每张地图都显示新手教程卡片。现在仅 release-smoke 诊断世界加载 canonical 已完成教程状态，最终矩阵同时断言 `tutorial_hidden_for_evidence=true`；真实新玩家教程不被跳过，仍由 51 项跨会话 E3 桌面旅程覆盖。

### BUG-QA-SOAK-PROFILE-COVERAGE-001 — qa-passed

旧 240 秒托管 artifact 只完成 3 个 Profile。当前 runner 使用“达到时间且至少完成 5 轮”的双条件，PowerShell 驱动和 workflow 再次核验 5 个唯一 Profile、最低循环数和零出生后传送。该结果只属于 hosted reference，不替代 7,200 秒目标硬件资格。

### BUG-QA-SKY-DESCENT-001 — qa-passed

五图长稳首次覆盖 `sky_islands` Seed `112361` 时，在第 18 步发现一格下坡的真实岛缘越界：路线已接近目标中心，但玩家在短暂空中阶段减速不足并跌落 5.26 米。修复没有更换种子、传送玩家或放宽 4 米跌落门槛，而是仅在下坡步骤通过正式 Input 限制接近速度并提前制动；精确 Seed 专项回归和五图长稳共同防止复发。

### BUG-QA-E4-SIGNOFF-001 — open / release blocker

自动化可以确认最终包可运行、路线可走、截图有细节、UI 没有明显布局错误、日志无 fatal；但无法独立替代人对手感、视觉重复、引导理解、所有重点遗迹/洞穴/水域/高空/边界的体验判断。需要独立复审者在最终候选包上完成签字。

### BUG-PERF-002 — open / external release blocker

已完成真实 frame-time 指标、五图最终包采集、外部 Working Set/Private Bytes、最低/推荐硬件 v1 策略和自动判定脚本。仍缺在真实最低/推荐 GPU 机器上执行并由发布负责人确认硬件身份的结果。

### BUG-SOAK-120-001 — open / external release blocker

`tests/release/run_target_hardware_qualification.ps1` 已强制：

- 非托管参考模式必须提供操作人；
- 严格持续时间不得低于 7,200 秒；
- 五图循环、至少 10 条完成路线；
- 无出生后传送、无 fatal、内存增长不超过策略阈值；
- 记录 CPU、GPU、驱动、系统、RAM、帧时、加载和内存。

GitHub 托管 Runner 只允许生成 `hosted_ci_reference`，绝不标记为最低/推荐硬件通过。
